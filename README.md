# Dra. Patrícia Andrade — Landing Page (Lifting Facial & Harmonização)

Landing Page de altíssima conversão, moderna, sofisticada e com estética editorial minimalista (**Minimalist Boutique / Editorial Architecture**) em Dourado Fosco (`#BFA87E`), Champagne Suave (`#DFD4C0`), Grafite Escuro (`#1A1918`), Off-White Aveludado (`#F9F8F5`) e Branco Puro (`#FFFFFF`) para a **Dra. Patrícia Andrade** — Biomédica Esteta especialista em Harmonização Facial, referência em Lifting Facial Não Cirúrgico (CRBM 35884) com atendimento privativo em Alphaville e Osasco - SP.

## 🚀 Tecnologias
- **React 18** + **Vite**
- **Tailwind CSS** (Paleta de cores customizada e micro-tipografia)
- **Lucide Icons**
- **Framer Motion**
- **Google Fonts:** `Plus Jakarta Sans` & `Inter` (100% Sans-Serif)

## 📱 Estrutura e Conversão Direta (Zero Quizzes)
- **Top Announcement Bar:** Aviso de atendimento e consulta de agenda.
- **Header Minimalista:** Navegação fluida e CTA de agendamento.
- **Hero Section:** Retrato oficial emoldurado com linhas arquitetônicas finas e copywriting focado em resultados naturais.
- **Trust Bar:** 4 pilares de autoridade (CRBM 35884, Alphaville & Osasco, Lifting Sem Cortes, Produtos Padrão Ouro).
- **Lifting Facial Não Cirúrgico:** Os 3 pilares estruturais da metodologia sem cortes.
- **Cardápio de Procedimentos:** 6 tratamentos exclusivos com botões de agendamento com mensagens parametrizadas para WhatsApp (`(11) 98534-3231`).
- **Matriz Comparativa:** Filosofia Dra. Patrícia Andrade vs Mercado Convencional.
- **Sobre a Especialista:** Autoridade clínica, biografia e 4 diferenciais de consultório privativo.
- **Depoimentos de Pacientes:** Relatos reais com 5 estrelas em dourado fosco.
- **Pre-Footer CTA:** 100% Full-Width em fundo sólido Dourado Fosco.
- **WhatsApp Floating Dock:** Botão flutuante fixo com indicador de pulso online.

## 💻 Como Rodar o Projeto
```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Build de produção
npm run build
```

Ou abra diretamente o arquivo `standalone.html` no seu navegador sem necessidade de servidor Node.js.
